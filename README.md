# Applied Data Science Capstone — SpaceX Falcon 9

This is a runnable starter repository for the Coursera Applied Data Science Capstone.
It includes a notebook and scripts for SpaceX API data collection, data preparation,
EDA, SQL analysis, Folium mapping, Plotly Dash, and classification models.

**Important:** This repository does not contain fabricated results. Run the notebook
from top to bottom to generate the actual charts, map, processed data, and model metrics.
Use those real outputs in your final Coursera presentation.

## Run
1. Install Python 3.10+.
2. Run `pip install -r requirements.txt`.
3. Run `jupyter lab`.
4. Open `notebooks/Capstone_Workflow.ipynb` and run all cells.
5. For the dashboard, run `python src/dashboard.py` after completing the notebook.

## Upload to GitHub
Create/open your `capstone` repository, choose **Add file → Upload files**, extract this ZIP,
select all files inside the `Capstone_GitHub_Project` folder, and commit to `main`.
